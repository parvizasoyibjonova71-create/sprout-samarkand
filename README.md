# Sprout Samarkand

A small web app that turns everyday sustainable actions into a growing plant. Built for Green Shift Hacks.

Users log recycled materials, water-saving habits and neighbourhood cleanups. Each action grows a plant, shows the CO2 and water saved, and can be shared as a short text. A Places tab lists recycling points and repair workshops in Samarkand.

## Run it

No install needed. Open `index.html` in any modern browser, or in VS Code use the Live Server extension.

## Data and limitations

- CO2 factors and water-saving estimates are approximate and must be checked against sources such as EPA WARM and WRAP.
- Places come from Google Maps listings and are marked "unverified" until confirmed by a call or visit.
- Data is saved only in the user's own browser (localStorage). There is no server or account.
- Cleanups count litter removed and volunteer hours; no CO2 claim is made for them.

## Built with

HTML, CSS and plain JavaScript (single file, no dependencies).
